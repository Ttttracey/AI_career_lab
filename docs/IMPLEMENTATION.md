# 实现细节与本地使用说明

中文、本地单用户的 AI 产品经理训练应用。界面采用米白色磨砂渐变、半透明表面和柔和层次。用户为明确的 `local-learner` 演示身份。数据通过服务端 Prisma 写入 SQLite，浏览器存储不充当数据库。

## 启动

需要 Node.js 22.12+（本次使用 24.22.1）和 pnpm 11.25.0。

```sh
cd AI_career_lab
pnpm install --frozen-lockfile
# 将 .env.example 复制为 .env，已有 .env 时保留
pnpm setup
pnpm dev
```

打开 <http://127.0.0.1:3000>。Windows 也可双击 `启动练习场.cmd`：它会检查依赖、初始化数据库，再启动本地应用。本机没有全局 pnpm 时，脚本会尝试 Codex 随附的 pnpm。

正式构建运行：

```sh
pnpm build
pnpm start
```

默认只监听 `127.0.0.1`。不实现登录、注册、支付或公开部署。

如由启动脚本开启了后台服务，可运行 `停止后台练习场.cmd`；它只会停止与本项目路径和端口匹配的进程，不删除数据。以后用启动脚本开启的前台服务，关闭其窗口即可停止。

## 可以完成的流程

- `/`：安静入口；每日一句按用户时区保存，同一天刷新不变化；主动“换一句”才切换。根据目标、诊断、进行中任务和草稿跳转。
- `/onboarding`：背景、产品经验、岗位、每日时间与时区；招聘原文保存、要求与原句映射、人工编辑确认；六道情境题草稿与初步诊断。
- `/onboarding/report`：六题完成后先看反馈，再确认建立路线。展示每题自己的原文、可继续展开的思路、优先补充的两项和可直接打开的短课/项目练习。未配置真实 AI 时使用明确标记的原文规则检查，不把关键词匹配当作理解判断或能力评分。已有六题回答可直接查看新报告；已有路线不重排、不覆盖。
- `/dashboard`、`/roadmap`：一个主要任务、安排原因、前置关系、日期、提前练习、顺序调整；新评价只产生可接受或忽略的调整建议。
- `/learn/l01` 至 `/learn/l12`：12 节完整短课、案例、每节三题、解释与上下文答疑；答对三题完成课程，20 经验值仅发放一次。
- `/projects/knowledge-assistant`：四阶段贯穿项目；固定 rubric、渐进提示、主动展开参考思路、Markdown 草稿、预览、独立正式版本、绑定版本的点评、指定版本成果导出。
- `/interviews`：文字或按轮语音；五道主问题，短回答可触发一次基于原文的澄清追问；最多十题；支持回答草稿、暂停、恢复、提前结束和重试下一题。
- `/interviews/[sessionId]/report`：完整问答、限定范围的反馈、可定位原文与后续练习。表达整理只使用用户原文，缺少事实明确标记待补充。
- `/profile`：学习记录、真实有效能力证据及历史、项目档案与版本、面试历史、数据 JSON 和成果 Markdown 导出。重置必须手工输入确认文字。

## AI 服务配置

仅在服务端 `.env` 配置；修改后重启服务。没有密钥时不用安装或连接任何 AI 服务。

```dotenv
DATABASE_URL="file:./dev.db"
OPENAI_API_KEY=""
AI_TEXT_MODEL="gpt-6-astra"
AI_TRANSCRIBE_MODEL=""
AI_SPEECH_MODEL=""
AI_SPEECH_VOICE="coral"
```

`AI_TEXT_MODEL`、`AI_TRANSCRIBE_MODEL`、`AI_SPEECH_MODEL` 彼此独立；请使用账户实际支持的模型名。转写、朗读都需要密钥与对应模型；留空时界面说明未配置并可切换文字。模型名仅是配置默认，不保证账户访问权限。

统一接口 `AIProvider` 封装 `analyzeJob`、`assessBaseline`、`buildLearningPlan`、`answerLearningQuestion`、`reviewSubmission`、`generateInterviewQuestion`、`reviewInterview`。`RealAI` 使用 OpenAI SDK 的 Responses 结构化输出；`DemoAI` 使用可解释的规则和教学提示。

无密钥时，所有独立功能可用；招聘解析、点评、答疑和面试均明确标识演示。演示评价的 `level` 永远为 `null`，不写入 `SkillEvidence`。演示模式不会针对文字质量作真实专业判断，不伪造语音转写。真实调用失败保留原文并提供重试，绝不静默回退演示。

接口设置输入上限、45 秒服务超时、关闭自动网络重试；结构验证之后还检查能力维度、资源 ID、引用的 sourceId 和逐字原文。无工具权限，招聘和作业仅作为不可信分析资料。输出渲染不执行原始 HTML。密钥不发送到浏览器、数据库或日志。

实现前核对的官方文档：

- [OpenAI 结构化输出](https://developers.openai.com/api/docs/guides/structured-outputs)
- [OpenAI 文件转写](https://developers.openai.com/api/docs/guides/speech-to-text)
- [OpenAI 语音合成](https://developers.openai.com/api/docs/guides/text-to-speech)
- [Next.js 安装](https://nextjs.org/docs/app/getting-started/installation)
- [Prisma SQLite](https://www.prisma.io/docs/orm/v6/overview/databases/sqlite)

## 语音与隐私

主动点击后申请麦克风。浏览器选择 WebM/Opus 或 MP4 格式；显示录音状态、时长、停止、取消和重录；120 秒自动停止。上传最多 10 MB，服务端检查体积、非空、声明格式与文件头。转写前后状态分开，识别文字需要用户修正或确认，之后才进入可提交回答。

录音只在当前页面和请求内存中暂存，发送到所配置的 OpenAI 转写服务，不写入本机临时文件或数据库；请求结束释放内存引用。确认成功后清除页面录音引用；切换文字、暂停、离开页面或取消都会停止麦克风。第三方服务的数据处理以其账户设置为准。提问语音标记为 AI 生成，播放失败仍可读题继续。

## 数据位置与可靠性

- 默认数据库：`prisma/dev.db`，相对于 Prisma schema 目录；保存学习记录、文字成果与资料字段。导入原文件另存于 `.local/uploads/`。完整备份前先停服务，再复制数据库、存在的伴随文件及 `.local/uploads/`。
- 迁移：`prisma/migrations/`；`pnpm db:migrate` 应用迁移。
- 种子：`pnpm db:seed`，可重复执行，不覆盖学习记录。
- 正式提交、已完成诊断原文和已提交面试回答有数据库不可变触发器；草稿与成果档案标记可更新。
- 正式提交请求键、课程/项目奖励事件、面试回答键、面试轮次和每日内容有唯一约束。单进程写队列与短事务避免重复写入；AI 网络调用期间不占用数据库事务。
- 课程完成、经验值和能力表现独立。每阶段首次提交 40 经验值、每场有回答的面试结束 30 经验值；不按答案质量奖励，不凭点击提高能力。
- 能力最近表现来自真实、引用校验通过的 `SkillEvidence`。0 表示已回答且有关键误解，`null` 表示待评估，两者不会混淆。所有结论标记证据范围、标准、模型和提示词版本。
- 所有用户记录关联 `userId`。这个版本没有认证，不适用于共享电脑多用户、互联网公开服务或多进程横向扩容。

## 检查与隔离测试

```sh
pnpm typecheck
pnpm test
pnpm build
```

数据测试用临时数据库，结束后清理，覆盖持久化、重复种子、幂等奖励、不可变版本、证据校验、面试状态和非法音频。

初步诊断回归还检查：完成六题时尚不创建路线；反馈引用严格对应各自题目；确认后才建立路线；对已有路线再次确认会保留其 ID、日期、顺序和状态。计划生成上下文含真实回答和本次反馈，新任务安排原因可追溯到对应题目。`onboardingStep=3` 表示用户从反馈页确认进入路线，旧数据无需重新答题或修改表结构。

HTTP 验证需要一个独立数据库与服务，**不要把测试 URL 指向你的日常学习数据库**：

```sh
pnpm exec tsx scripts/verify-flow.ts --prepare
# 新开终端：设置 DATABASE_URL 为 test-results/browser.db 的绝对 file: 路径
# PowerShell 示例：
$env:DATABASE_URL = "file:C:/absolute/path/ai-career-lab/test-results/browser.db"
pnpm exec next dev --hostname 127.0.0.1 --port 3001
# 另一终端：
pnpm test:flow
```

HTTP 验证脚本为一次完整验收流程；复跑时应使用新建的隔离测试库。详见 [验收记录](../VALIDATION.md)。

## 本次合理默认与边界

新建目录 `ai-career-lab`，此前工作区为空且无适用 AGENTS.md；Next.js 开发服务随后生成的项目 AGENTS.md 已保留。采用 Next.js App Router 16.4.3、React 19.2、TypeScript、Tailwind 4、shadcn 风格 Button（Radix Slot/CVA）、Prisma 6.19 与 SQLite。选择 Prisma 6 稳定分支以使用已验证的内置 SQLite 引擎，锁文件固定实际依赖。

只提供 AI 产品经理这一目标体系。岗位名称可编辑，课程与能力维度固定。计划按基础前置链、岗位与每日时间安排，AI 只引用已有资源；有效能力证据不足时不伪装成精准个性化。新目标与时间不会悄悄重写已有安排；路线支持手工调整。

每日内容只有原创思考和鼓励语，没有新闻抓取或未核验行业动态。来源字段为空代表没有引用外部材料，不是“已核验”。默认 Asia/Shanghai，每天 30 分钟。课程与项目背景均为原创模拟内容。

真实 OpenAI 文本、麦克风录音、转写与合成的在线结果尚未实测，因为本次未配置密钥和语音模型。已实现相关接口与失败降级界面；需要你配置后用实际浏览器录音验证。没有实现注册、招聘抓取、投递、社区、支付、公开部署和实时插话语音。

## 教程闭环升级：历史、资料库与阶段复测

从「成长档案」进入三个新入口：

- `/profile/records` 我的资料与历史：按类型、关键词查询背景与目标、招聘原文、首次诊断、小测提交、项目草稿及正式版本、学习答疑、面试和复测。升级前只有最近状态的资料明确标为「已有记录归档」，不会伪造更早的编辑历史。新背景、招聘修改和题库内容修改保存独立版本。
- `/profile/library` 资料与题库：手动添加，或上传 JSON、CSV、Markdown、TXT、文字型 PDF。先预览，再选择入库；正文和选项相同的内容跳过；无效行保留错误信息，不进入学习资源。导入后为待核对，修改已核对内容会重新变为待核对。查看原文、出处、原始文件、能力和课程关联，留下核对依据后才启用。题目还必须补齐参考要点和固定评价标准。
- `/profile/retests` 阶段复测：每轮六道情境题，每维度一题；先用未做过的题，之后提示重复。支持草稿、暂停、恢复、独立回答快照和反馈重试。只并列展示同标准的真实有效表现，演示或证据不足仍为待评估，不产生增长率或岗位匹配率。

内置 **48 道原创训练题**：36 道课程小测、12 道平行情境题。它们不是企业真题。已核对题目可直接练习；选择题使用固定答案检查理解，情境题按固定标准点评。练习原文和题目快照不可覆盖，修改资料不改变旧提交。

已核对资料可以关联课程，出现在学习页并带入答疑上下文，也可由用户主动加入现有成长路线。待核对/退回的内容不能用于答疑、练习或加入路线；导入不会自动重排用户计划。资料阅读和题库练习不额外增加能力或发放经验值。

PDF 提取仅在本机运行 Python + `pypdf`，不发给 AI。每份文件最多 10 MB、100 页；PDF 按页拆分，页内超长文本再拆段，位置保留原页码。扫描件需先 OCR。配置 `PYTHON_EXECUTABLE` 可指定 Python；本机已验证随附 Python。其他环境可运行 `python -m pip install pypdf`。JSON/CSV 每批最多 300 条，每条正文最多 24000 字符，CSV 数组字段使用 JSON 数组。可在页面下载 JSON 模板，不支持直接解析 Excel 工作簿，请另存为 CSV。

四份用户提供教程的原文件与人工整理的方法摘要已存入本机；摘要保持待核对，不冒充真实企业知识或用户经历。教程提到但未提供的外部题库没有导入。可选的 `pnpm exec tsx scripts/import-tutorials.ts "D:/your-pdf-folder"` 重复执行会跳过已有内容，此脚本不属于普通种子步骤。

建议先补 3–5 份实际目标岗位要求，保存原文与链接；再添加自己的访谈、项目和测试材料。有权使用的题目可按模板整理。招聘原文仍从目标设置参与岗位分析，项目作品仍通过项目工作台正式提交，参考资料不自动成为个人能力证据。

JSON 数据导出包含资料元数据、导入预览、历史与回答，不嵌入原始文件二进制；请分别下载原文件或备份上传目录。资料库支持独立 JSON 导出。确认重置会清除导入内容、原文件及学习记录，内置课程和原创题目会重新初始化。

扩展 HTTP 验证：先按上文准备一个全新的隔离数据库与服务，执行完整流程后，再设置同一 `TEST_BASE_URL` 运行 `pnpm exec tsx scripts/verify-library-flow.ts`。它验证四种实际导入格式、预览去重、原文件下载、未核对内容阻断、练习幂等与复测报告。不要指向日常学习服务。

## 学习交互与页面接续

12 节短课各有一个原创「产品决策小剧场」，每个情境提供两条可比较的路径。选择后展开可能后果、适用限制与继续思考的问题；这些是假设情境，不声称实际业务效果。选择存入本地历史，同一选择重复请求不重复归档；换路径会留下新版本，不加经验值或能力分。

小测采用逐题作答，可回看任意一题，切到下一题前先保存。三题提交后展开结果和解释，并根据现有计划、完成状态、前置条件及资源是否可用给出下一站。用户主动提前开始的安排会保留；完成卡不会暗中调整其他节点。

项目反馈可直接带回对应阶段的草稿：保留原版本、维度和原文引用作为改稿提示，已有草稿不会被替换。通过版本链接切换时会打开指定版本。短课到项目、课程关联资料、资料筛选到详情均保留明确的返回位置。资料库关键词和筛选存入 URL，返回和刷新可以恢复。

主导航、档案分类和项目阶段显示当前位置。客户端短时复用已成功读取的状态，跨页继续向服务端刷新，减少重复加载整页的闪动；数据库仍是持久化来源。展开和卡片切换只有短暂过渡，遵循减少动态效果偏好。首屏仍保持原有单一主行动。

这次交互迭代没有改动课程的基础排序，也没有把演示反馈变为真实评价。更深入的岗位个性化仍需要改善任务选择逻辑、真实反馈质量，并验证不同学习者能否获得不同且合理的练习安排。
